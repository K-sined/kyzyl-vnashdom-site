# Приём заявок с квиза на reg.ru

С 24.09.2026 заявки квиза «Подобрать материалы» сохраняются в MySQL на reg.ru, а не в Google Таблицы. Причина: закон требует собирать персональные данные граждан РФ в базах на территории России (ч. 5 ст. 18 152-ФЗ). Обе копии сайта — kyzyl.vnashdom.ru и GitHub Pages — отправляют заявки на `https://kyzyl.vnashdom.ru/api/lead.php`.

## Установка (один раз)

1. **База.** ISPmanager → «Базы данных». Можно взять ту же базу, что и для розыгрыша. phpMyAdmin → эта база → «Импорт» → `schema.sql` → «Вперёд». Появится таблица `site_leads`.
2. **Настройки.** Скопируйте `config.sample.php` в `config.php` и впишите доступ к базе, код для просмотра заявок и почту для уведомлений. Загрузите `config.php` в папку `/api/` на хостинге. В git он не попадает.
3. **Проверка.** Отправьте тестовую заявку с сайта. Откройте `https://kyzyl.vnashdom.ru/api/zayavki.html`, введите код — заявка должна появиться, на почту должно прийти письмо. Удалите тестовую заявку кнопкой «Удалить».

Пока `config.php` не загружен, квиз показывает клиенту «Не удалось отправить заявку, позвоните нам» с номерами телефонов. Заявки не пропадают молча.

## После установки

- Выгрузите старые заявки из Google Таблицы «Заявки с квиза» и перенесите нужные в работу. Затем **очистите таблицу и отключите веб-приложение Apps Script** (Развернуть → Управление развёртываниями → Архивировать).
- Заявки старше 12 месяцев удаляются автоматически — такой срок указан в политике.
- Если клиент просит удалить свои данные, удалите его заявку кнопкой «Удалить» в `zayavki.html`.
